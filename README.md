# RegimeDip (stricter regime) — CBBTC race bot

Long-only CBBTC bot for the 24-hour BTC race: at most four full-size trades per window — dip buys after a sharp, contained pullback with an oversold RSI, and rebound buys after a deep washout with a long lower wick and a strong bounce. Every trade carries a stop plus a take-profit or trailing exit, and a 60-bar cooldown follows each exit. The dip regime filter only allows entries while the 360-bar trend is no worse than -50 bps.
